# Latent Conditioned Loco-Manipulation Using Motion Priors

This repository contains the source code for the website of *Latent Conditioned Loco-Manipulation Using Motion Priors* by Maciej Stępień, Rafael Kourdis, Constant Roux and Olivier Stasse (accepted for the 2025 IEEE-RAS 24th International Conference on Humanoid Robots (Humanoids)).
